# visionbord

ワークショップ「ゆめかな ビジョンボード作成会」の参加者向けWebツールです。
5つの問いに答えると、ChatGPTに貼り付けるだけで自分のビジョンボード画像を
生成できるプロンプトが完成します。

## 使い方

`index.html` をブラウザで開くだけで動きます。サーバーもログインも不要です。
入力した内容はどこにも送信・保存されません（コピー用のプロンプトが画面に表示されるだけです）。

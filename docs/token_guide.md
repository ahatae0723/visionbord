# Threads アクセストークン取得ガイド（画面操作つき）

**アクセストークンとは？**
あなたのThreadsアカウントのデータ（閲覧数など）を、プログラムが代わりに見に行くための「合鍵」のような長い文字列です。パスワードと同じくらい大切なものなので、**人に見せない・GitHubの公開ページに貼らない**が鉄則です。

所要時間の目安: 30〜40分（Metaの画面をゆっくり進めて大丈夫です）

> ⚠️ Metaの管理画面は時々デザインが変わります。ボタンの名前が多少違っても、近い意味のものを探してください。どうしても見つからないときは、画面のスクリーンショットを添えてClaudeに質問してください。

---

## ステップ1: Meta for Developers に登録する

1. ブラウザで **https://developers.facebook.com/** を開く
2. 右上の「ログイン」から、**お持ちのFacebookアカウント**でログイン
   - Facebookアカウントがない場合は先に作成が必要です（Threadsのアカウントとは別物です）
3. 初めての場合「開発者として登録」画面が出るので、電話番号認証などを済ませて登録完了

## ステップ2: アプリを作る

「アプリ」といってもスマホアプリを作るわけではなく、**「データを取りに行く窓口」をMetaに登録する**だけです。

1. ログイン後、右上の「マイアプリ」→「**アプリを作成**」をクリック
2. ユースケース（何をしたいか）を聞かれたら「**Threads APIにアクセス**（Access the Threads API）」を選ぶ
3. アプリ名を入力（例: `threads-insights`）。名前は何でもOK
4. 連絡先メールアドレスを確認して「アプリを作成」→ パスワードを聞かれたら入力

## ステップ3: 必要な権限を有効にする

1. アプリの管理画面（ダッシュボード）が開いたら、左メニューの「**ユースケース**」→ Threads の「**カスタマイズ**」を開く
2. 「権限（Permissions）」の一覧で、次の2つを**追加**する:
   - `threads_basic` … アカウントの基本情報を読む権限（最初から入っていることが多い）
   - `threads_manage_insights` … 閲覧数などのインサイトを読む権限 ←**これが重要**

## ステップ4: 自分のThreadsアカウントを「テスター」として登録する

作ったアプリが、あなたのThreadsアカウントにアクセスしてよいと許可する作業です。

1. アプリ管理画面の左メニュー「**アプリの役割**（App roles）」→「**役割**（Roles）」を開く
2. 「**人を追加**」→ 役割は「**Threadsテスター**（Threads Tester）」を選ぶ
3. あなたのThreadsのユーザー名 `ai_hattatu.schoolsocialworker` を入力して送信
4. **Threads側で招待を承認する**:
   - スマホの Threads アプリ →「設定」→「アカウント」→「**Webサイトのアクセス許可**」→「**招待**」
   - （見つからない場合はブラウザで https://www.threads.net/settings/account を開く）
   - 届いている招待を「承認」する

## ステップ5: アクセストークンを発行する

1. アプリ管理画面の「ユースケース」→ Threads の「カスタマイズ」→「**設定**」を開く
2. 「**ユーザートークン生成ツール**（User Token Generator）」の欄に、ステップ4で承認した自分のアカウントが表示されているはず
3. 「**トークンを生成**（Generate Token）」をクリック
4. Threadsのログイン・許可画面が出るので、内容を確認して**許可**する
5. 表示された長い文字列（`TH...` で始まることが多い）が**あなたのアクセストークン**です
6. **コピーして、パスワード管理アプリやMacの「メモ」など安全な場所に一時保存**してください
   - ⚠️ LINEで人に送ったり、SNSに貼ったりしないこと

> 💡 この方法で発行されるトークンは「**長期トークン（約60日有効）**」です。
> このシステムには**毎週自動で延長する仕組み**（`トークン自動延長` ワークフロー）が入っているので、
> 後述のGitHub設定（docs/setup_github.md の GH_PAT）まで済ませれば、基本的に取り直しは不要になります。

### もし「ユーザートークン生成ツール」が見つからない場合（別ルート）

画面構成が変わって生成ボタンが見つからない場合は、スクリーンショットを添えてClaudeに「トークン取得の続きを手伝って」と聞いてください。認証用URLを一緒に組み立てる方法（少し手順が多い）でも取得できます。

---

## トークンが切れたとき（復旧手順）

「日次取得が失敗しました」というIssue（お知らせ）がGitHubに作られたり、レポートに⚠️が出たりしたら、トークン切れの可能性が高いです。

1. 上の**ステップ5**をもう一度やって、新しいトークンを発行する
2. GitHubのデータ用リポジトリを開く →「**Settings**」→「**Secrets and variables**」→「**Actions**」
3. `THREADS_ACCESS_TOKEN` の右の鉛筆マーク（編集）→ 新しいトークンを貼り付けて「**Update secret**」
4. 「**Actions**」タブ →「日次インサイト取得」→「**Run workflow**」で手動実行して、緑のチェック✅になれば復旧完了
5. お知らせIssueが開いていたら「Close issue」で閉じる

## よくある質問

**Q. トークンが漏れたかもしれない！**
A. Meta for Developersのアプリ管理画面でアプリを一時停止するか、Threadsの「設定 → アカウント → Webサイトのアクセス許可」からアプリの接続を解除すれば、そのトークンは使えなくなります。その後、新しいトークンを発行し直してください。

**Q. お金はかかる？**
A. Threads APIもGitHub（この使い方の範囲）も無料です。

**Q. 誰かに勝手に投稿されたりしない？**
A. このシステムが使う権限は「読む」ものだけ（`threads_basic` と `threads_manage_insights`）です。投稿する権限（`threads_content_publish`）は付けていないので、投稿はできません。
